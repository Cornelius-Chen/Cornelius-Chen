# Architecture thesis · learning with visible evidence

[← Portfolio overview](README.md)

The question behind this portfolio is: **how can an AI system accumulate useful judgment and apply it to new work without making its evidence, limits, and human authority disappear?**

## Two real research loops

**Design domain:** admitted source or example → practice and variation → conditional design judgment → scope-filtered use on a new brief → comparison and review. The implementation can carry an experimental judgment forward; it cannot yet claim a human-validated quality gain.

**Trader research:** Puretelligence's point-in-time evidence → Jervis worker's domain reasoning → historical replay and simulated action → outcome diagnosis → source-linked candidate experience → a later research question. The diagnostic learning loop has executed; profitability, live response, and real order execution remain unproven.

## The local tool work

The media pipeline and desktop-control pipeline are concrete architecture work in their own right. The former moves from model tool call to Qwen-Image-2.1 first frame, asynchronous MiniMax H3 job, completion receipt, and inline artifact. The latter narrows Cua Driver's native desktop surface into seven model-facing MCP tools with target identity, action budget, policy, observation, and post-action readback. Qwen 3.5 9B is the active route; 27B is a recorded alternate that is currently out of local routing. The tool plumbing has local successes and known model-level limits. It does not prove general autonomous computer work.

## What would count as a fuller integration

The separate systems would need an explicit shared case identity, permission handoff, provenance references, reviewed outcome, and fresh-task evaluation. A diagram arrow alone does not supply those contracts. A complete run would still be different from a new capability that beats its baseline and receives independent approval.

The diagram and case notes label these limits because the architecture is most useful when a reviewer can tell **what exists, what was observed, and what remains to be proved**.
